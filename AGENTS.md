# Agent Instructions

#Project Overview
- The goal of this project is to build a Link-16 J28.2 formatter to allow operators to quickly build platform specific formatted messages, allow the operator to copy that message, and display how that message will format in the aircraft after it applies it formatting rules.

#Restrictions
- Verify both tabs in a browser: live uppercase output, final EOM, indexes, slash spacing/restrictions, segment-limit warnings, total character counts, and copying. Check narrow-screen layout and keyboard tab navigation after UI changes.
- Use only HTML/CSS/JS. There should be no build step required, this project can only ever exsist as a single .html file
